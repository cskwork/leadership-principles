# 원칙 · 내가 이끄는 방식

결정이 어려울 때 다시 펴 보는 열다섯 개의 리더십 기준. 매일 하나씩, 결정 앞에서 다시.

**Live:** https://cskwork.github.io/leadership-principles/

읽기 위한 것이 아니라, 지키기 위한 것. 내가 따르는 15가지 리더십 원칙을 언제든 펼쳐 보고 실제 결정에 적용하기 위한 한 장짜리 참조 사이트입니다.

## 기능

- **15개 원칙**: 한 줄 요지, 상세 설명, 그리고 "이렇게 실천한다" 행동 지침
- **오늘의 원칙**: 날짜를 기준으로 매일 하나의 원칙을 환기
- **한국어 / English** 토글 (기본값은 브라우저 언어, 선택은 저장)
- **라이트 / 다크 모드** (시스템 설정을 따르며 선택은 저장)
- **검색 필터**: 제목과 내용으로 즉시 좁히기
- **키보드 접근성**: 상세 보기에서 좌우 방향키로 원칙 이동, Esc로 닫기

## 로컬에서 보기

의존성이 없는 단일 `index.html`입니다. 브라우저로 바로 열거나, 정적 서버로 띄울 수 있습니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 기술

순수 HTML / CSS / 바닐라 JavaScript. 빌드 단계 없음. 타이포그래피는 Pretendard, Newsreader, Noto Serif KR. GitHub Pages 정적 호스팅.

이 원칙들은 제가 일하고 이끄는 방식을 정리한 개인적인 기준입니다. 누구든 자유롭게 참고하셔도 좋습니다.
